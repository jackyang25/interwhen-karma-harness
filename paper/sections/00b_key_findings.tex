\begin{itemize}\setlength\itemsep{3pt}
  \item \textbf{No verifier-guided extractor beats the forced-tool
        baseline.} All four B$'$+E pipelines land within $0.9$ pp of
        B$'$ ($71.6$--$72.5\%$); none of the four B$'$+E pipelines
        clears its pre-registered contrast (all $p_{\text{Bonf}} = 1.0$).
  \item \textbf{Accuracy comes from tool use, not verification.} The
        only significant primary contrasts are B vs A ($+8.7$ pp) and
        B$'$ vs B ($+21.3$ pp); forced tool use is the dominant lever.
  \item \textbf{No architectural axis carries an effect.} Placement
        (upfront vs reactive, $p = 0.79$), citation grounding
        ($p = 0.80$; half of all spans failed substring validation),
        and $k=3$ voting ($p = 0.89$; $23.7\%$ of field-votes reached
        no majority) are all null.
  \item \textbf{Reactive extraction is the cost-efficient pipeline.}
        It matches upfront accuracy at $\sim$$40\%$ of the token cost
        ($32$K vs $79$K per vignette); $k$-shot is costliest and
        slowest for no gain.
  \item \textbf{The null is informative.} The same mechanism
        \emph{harmed} accuracy when un-gated (pilot diagnostics);
        best-practice hygiene removes that harm and returns the
        verifier to parity with B$'$. The binding constraint is the
        LLM-extracted reference layer, not the verifier.
\end{itemize}
